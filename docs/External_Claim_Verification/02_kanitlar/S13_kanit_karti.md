Kısa özgün alıntı:

> represent such numbers as JSON strings

Desteklediği sınırlı iddia: JCS deterministik gösterim tanımlar; daha yüksek hassasiyetli değerler için string yaklaşımını önerir.

Local modele taşınamayacak sonuç: String içindeki 0.10 ve 0.1 domain eşdeğerliğini kendi başına normalleştirmez; JCS zorunlu local seçim değildir.
