## Rejected numeric approaches
- Binary float as default economic state: **REJECT**.
- epsilon as economic equality: **REJECT**; use exact representation + declared tick/step quantization.
- unknown/null/unsupported to numeric `0`: **REJECT**.
- scalar addition across different assets/units without conversion event/rate/source: **REJECT**.
- venue-specific liquidation/margin formula labeled universal: **REJECT**.
