## 8. Time, ambiguity, EOF, gap, duplicate, late event
Historical economic ordering uses event/bar/effective time, not processing time. Ambiguity cannot invent a suffix; only committed prefix survives. EOF is an explicit outcome rather than an implicit fill. Known duplicate is idempotent; conflicting duplicate becomes CONFLICT; genuinely new late event enters reconciliation/recovery. Feed/data gaps are explicit STALE/GAP/INDETERMINATE states unless a versioned repair transform exists.

## 9. Core/API contract etkisi
Core owns acceptance and economic mutation. API returns typed exact numeric strings, explicit state/result taxonomy, model/profile/version/hash identities, and source/effective times. API must not expose a display-formatted value as economic authority. Unsupported/unknown/blocking fields remain tagged, not numeric zero.

## 10. Persistence/replay/hash etkisi

Replay must be deterministic under the same identity tuple. Canonical hash supports comparison but is not the only oracle; field-level independent comparison is required.

## Read-only feed
Public market feed adapter has no order credential and no venue order write path. Coinbase public WebSocket can be used without API keys for certain subscriptions [S36]. Local simulated execution IDs must use own namespace; never present as live venue execution IDs.

## Sequence/gap/reconnect
Coinbase documents increasing sequence numbers and that gaps/out-of-order can occur [S36]. Bybit public trades expose system timestamp, trade fill timestamp and sequence behavior [S37].

State:
`CONNECTED -> FRESH -> STALE/GAP -> RECONCILING -> FRESH` or `FAILED`.
No new economic simulated decision while required market state is stale/gapped unless policy explicitly allows degraded mode and records it.

## Clock
Store source event time and receive time separately. Clock skew metric may warn; receive time never rewrites source event time.

## Recovery
After reconnect, obtain snapshot/catch-up mechanism appropriate to chosen feed; if gap cannot be reconciled, start a new runtime segment and mark previous continuity broken.

## Decision
Read-only demo and local execution identity **ACCEPT**. Exact reconnect algorithm adapter-specific **CONDITIONAL**.
