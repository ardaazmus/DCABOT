## 7. Asset/unit/precision/rounding
Economic inputs are parsed from decimal strings or exact integers. Internal arithmetic may use Decimal/Fraction; venue quantization occurs at the declared order/fee/margin boundary, never at UI formatting. Asset/unit tags are mandatory for qty, notional, fee, funding, margin and reserve. Rounding mode is part of the model/profile identity; missing rounding owner fails closed.

## 8. Time, ambiguity, EOF, gap, duplicate, late event
Historical economic ordering uses event/bar/effective time, not processing time. Ambiguity cannot invent a suffix; only committed prefix survives. EOF is an explicit outcome rather than an implicit fill. Known duplicate is idempotent; conflicting duplicate becomes CONFLICT; genuinely new late event enters reconciliation/recovery. Feed/data gaps are explicit STALE/GAP/INDETERMINATE states unless a versioned repair transform exists.

## 9. Core/API contract etkisi
Core owns acceptance and economic mutation. API returns typed exact numeric strings, explicit state/result taxonomy, model/profile/version/hash identities, and source/effective times. API must not expose a display-formatted value as economic authority. Unsupported/unknown/blocking fields remain tagged, not numeric zero.

## 10. Persistence/replay/hash etkisi

## Sizing units
- BASE sizing: `q_base` BASE_ASSET.
- QUOTE sizing: `a_quote` QUOTE_ASSET; candidate qty `q=a_quote/price`, sonra venue quantity-step quantization.
- Balance-percent: `budget = eligible_balance * pct`; `eligible_balance` tagged source olmalı, total wallet ile available/reserved balance karıştırılmamalı.

## Ladder
Generic custom ladder `A_i` order amounts ve deviation `d_i` listelerinden oluşabilir. Geometric amount multiplier örneği `A_i=A_0*m^i`; ancak bu strategy policy’dir, domain standardı değildir. Binance/Bybit bot parametreleri multiplier davranışlarının ürün-specific olduğunu gösterir; competitor behavior evidence olarak sınırlıdır.

## Invariants
`sum(posted_quote_commitments) <= max_budget`; `exposure_after_candidate <= max_exposure`; `sum(ladder_allocations) <= configured_budget`; all comparisons same unit.

## Rounding
1. Economic target exact Decimal.
2. Venue quantity step owner instrument profile.
3. Price tick owner instrument profile.
4. Notional minimum post-quantization kontrol edilir.
5. UI preview rounded display olabilir fakat accepted order exact serialized values backend’den gelir.

## Reinvest
Only `realized_profit_eligible` can increase future budget. Unrealized PnL reinvest default **REJECT**. Fee/funding deducted realized result ayrı ledger kalemi.

## Failure
Unknown balance, missing price conversion, unknown step/tick -> `INDETERMINATE/UNSUPPORTED`; zero varsayma.

## Decision
Exact sizing model **ACCEPT**; balance source ve venue metadata local/profile-specific **CONDITIONAL**.
